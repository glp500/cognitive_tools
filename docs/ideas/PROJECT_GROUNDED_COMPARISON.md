# Source-grounded comparison of the commons visibility study

**Audit date:** 2 October 2026. **Scope:** the current `balanced_capacity_v1` Stage-5 study, its population-payoff gate, the completed pilot/full campaigns, and the code that generated and analyzes them. This is a design and evidence audit, not a new simulation or a claim that the model reproduces any external benchmark exactly. Links to local files point to the implementation; external links point to original papers, project repositories, or official documentation. “Observed” means verified in this repository or its retained outputs. “Inference” marks a conclusion drawn from those observations and cited work.

## Decision in one paragraph

**Keep the present Mesa/PettingZoo model as the primary research instrument.** Its tested, 64-player, renewable-resource game passes the *N-player sequential social-dilemma* payoff conditions for the frozen always-low/always-high policy pair in all three capacity-matched landscapes. That claim is narrower than “all policies, rewards, horizons, or resource conditions are dilemmas,” and narrower than a claim about real human commons behavior. The study's distinctive estimand is how an explicitly constructed, rewiring **attention graph** changes the representativeness of four observed peers; neither Melting Pot's nor SocialJax's Harvest is a drop-in implementation of that graph, capped reward, or matched landscape experiment. The lowest-cost path is to improve documentation, timing/construct checks, provenance, and targeted robustness within this codebase. A framework port would create a new game and require a new payoff gate and new pilot/full results. This judgment follows the [N-player Schelling-diagram definition](https://proceedings.neurips.cc/paper/2018/file/7fea637fd6d02b8f0adf6f7dc36aed93-Paper.pdf), the [Melting Pot 2.0 protocol](https://arxiv.org/abs/2211.13746), the [SocialJax implementation](https://github.com/cooperativex/SocialJax/blob/main/socialjax/environments/common_harvest/harvest_open.py), and the local [study specification](../specs/capacity-matched-visibility-study.md).

The implemented game is a simultaneous-move, partially observed, temporally extended commons: stationary users repeatedly extract from a spatial renewable stock, and actions change future resource availability. The ecological update is a project-specific discrete equation, `R' = clip(R + rR(1−R/K) − dR + c(neighbor_mean(R)−R), 0, K)`, applied **after** harvest ([`ecology.py`](../../cognitive_tools/ecology.py#L226-L307)). The model's environmental-feedback idea is consistent with the general coupled strategy/environment framing of [Tilman, Plotkin, and Akçay (2020)](https://www.nature.com/articles/s41467-020-14531-6), but their equations and this discrete spatial rule are not identical. Independent agents use a three-bin ecological state or a nine-bin ecological/social state, tabular Q-learning, and an epsilon-greedy training policy ([`qlearning.py`](../../cognitive_tools/qlearning.py#L41-L84), [`qlearning.py`](../../cognitive_tools/qlearning.py#L92-L272), [`experiment.py`](../../cognitive_tools/experiment.py#L536-L581)). It should be described as a **stylized computational model**, not as a calibrated empirical reconstruction of a particular commons.

## Does the payoff gate establish a social dilemma?

Yes, **for the operational N-player criterion and frozen test conditions**. [Hughes and colleagues' N-player formulation](https://proceedings.neurips.cc/paper/2018/file/7fea637fd6d02b8f0adf6f7dc36aed93-Paper.pdf) uses a Schelling diagram of focal C/D returns against the number of cooperative others. It requires (1) all-C return greater than all-D return, (2) all-C return greater than the return to a cooperator among defectors, and (3) fear or greed. The local classifier checks these as collective gain `G > 0`, exploitation gap `E > 0`, and `fear > 0` or `greed > 0` ([`payoff_analysis.py`](../../cognitive_tools/payoff_analysis.py#L17-L60), [`payoff_analysis.py`](../../cognitive_tools/payoff_analysis.py#L322-L374)). Its 100 held-out replicates per landscape, four focal agents, 1,000-step horizon, and 5,000 simultaneous-bootstrap resamples yielded positive lower bounds for G, E, and fear under both summed and discounted capped utility in all three maps; greed was zero ([gate review](../reviews/balanced-capacity-payoff-gate-2026-10-01.md), [retained verdicts](../../results/payoff_validation/balanced_gate_v1/analysis/verdicts.csv)). This is a **fear-supported commons dilemma**, not a Prisoner's Dilemma that requires both greed and fear.

The classification should cite the **N-player** extension rather than present the result as an exact application of the earlier two-player payoff matrix in [Leibo et al. (2017)](https://arxiv.org/pdf/1702.03037). Hughes et al. also define an *intertemporal* dilemma more strongly: short-horizon selfish defection must be individually optimal while damaging long-term group welfare. The current gate tests 1,000-step returns, not that short-horizon condition. Moreover, when stock is plentiful both requested amounts can yield the same immediate **capped** reward of 0.002; immediate temptation is therefore not established by the high-extraction label alone ([`env.py`](../../cognitive_tools/env.py#L164-L169)). The safe manuscript wording is: **“a 64-player sequential commons dilemma under the tested C/D policies and capped reward, with fear-supported payoff inequalities.”** Treat “intertemporal dilemma,” “universally validated game,” and “learned cooperation” as separate, currently unsupported claims. A short-horizon payoff scan would be needed for the first. [Hughes et al.](https://proceedings.neurips.cc/paper/2018/file/7fea637fd6d02b8f0adf6f7dc36aed93-Paper.pdf) explicitly distinguish commons depletion from public-goods contribution.

## What the completed experiment actually found

The 11-treatment full campaign completed 3,300 condition-replicates and the recovered analysis passed its recorded coverage and matched-graph health checks ([full-run audit](../reviews/balanced-full-run-recovery-2026-10-01.md)). The primary H1 within-run association was **−0.088** (95% replicate-cluster interval −0.111 to −0.066), opposite the predicted positive sign. Its linear-time-adjusted counterpart was **+0.035** (+0.026 to +0.046), and the treatment-centered association among run means was **+0.114** (+0.044 to +0.184). These answer different comparison questions; their sign reversal makes an unconditional “inequality increases distortion” claim untenable. H2's pooled segregated−dispersed error contrast was **+0.100 percentage points** (−0.013 to +0.219), so the directional prediction is unresolved, not disproved or shown equivalent. H3's pooled adaptive−fixed contrast was **−0.118 percentage points** (−0.199 to −0.040), a small improvement in the predicted direction. H2/H3 directions were informed by the earlier exploratory pilot, so call the full study an independent follow-up to pilot-informed hypotheses, not a preregistration completed before all relevant data existed ([full-run audit](../reviews/balanced-full-run-recovery-2026-10-01.md)).

For RQ2, the recorded descriptive means are resource fraction 0.192 in dispersed versus 0.221 in segregated, reserve welfare 0.857 versus 0.860, and wealth Gini 0.420 versus 0.443. Adaptive observation raised terminal visibility Gini in all 15 matched cells, while low-extraction contrasts changed sign across cells; their pointwise intervals did not exclude zero ([full-run audit](../reviews/balanced-full-run-recovery-2026-10-01.md)). These are model outcomes conditional on the chosen parameters and agents. The resource/welfare differences are not an independent test of H2, and the pointwise cell intervals should not be read as a familywise set of confirmatory tests.

One code-level timing caveat deserves explicit attention. During training, the agent chooses `a_t` using graph `G_t` and previous actions; at rewiring steps the graph is then updated to `G_(t+1)` before the saved checkpoint computes error for `a_t` ([`experiment.py`](../../cognitive_tools/experiment.py#L1026-L1058), [`experiment.py`](../../cognitive_tools/experiment.py#L1064-L1147)). In the pilot/full campaign, **both recording and rewiring occur every 50 steps**, so scheduled checkpoints at 50, 100, …, 5,000 use the post-rewire graph ([`run_balanced_campaign.sh`](../../scripts/run_balanced_campaign.sh#L12-L18), [`run_balanced_campaign.sh`](../../scripts/run_balanced_campaign.sh#L58-L65)). That graph and `a_t` also define the social signal used in the next encoded state. **Inference:** H1 tracks the representativeness of the *next decision's available view* at those checkpoints, not the information that informed action `a_t`. Report this phase precisely; a future clean replication could log both pre- and post-rewire error to measure the immediate effect of a rewiring event. Do not silently relabel the existing series as a pre-action belief error.

The linked source pages were inspected as published or on their live `main` branch on 2 October 2026; `main` links are not immutable commit references, so pin a commit before any future code adoption.

## Methodological judgment and cheapest ordered refinement

1. **Write one model-and-analysis contract before altering behavior (low effort).** Convert the current [study specification](../specs/capacity-matched-visibility-study.md) and equations into an ODD-style model description: entities, state variables, schedule, observation graph direction, action/reward semantics, landscape generation, initialization, submodels, parameter table, and phase-specific outcome definitions. Add a TRACE-style evidence table linking each mechanism to unit tests, payoff gate, pilot/full result, and sensitivity check. The [ODD update](https://www.jasss.org/23/2/7.html) and [TRACE paper](https://www.sciencedirect.com/science/article/pii/S0304380014000611) supply established reporting structures; Schrama et al.'s [replication repository](https://github.com/bobbyleg/Centrality_and_environmental_impact/tree/main/Paper) shows a particularly close ODD precedent. **Pass condition:** another researcher can reconstruct the exact timestep order, graph direction, three landscapes, reward, and H1/H2/H3 estimands from the document without reverse-engineering code.

2. **Verify the interface and measurement timing (low effort, no retrospective data rewrite).** Run the official [PettingZoo parallel and seed tests](https://pettingzoo.farama.org/content/environment_tests/) against the exact `EcoEnv` configuration. Add a tiny deterministic trace check around a step that rewires, asserting the distinction among graph used for action, graph used for forecast error, and graph used for the saved metric. For a **new** run, record pre- and post-rewire local-view error to distinguish the information that informed `a_t` from the information available at `t+1`. **Pass condition:** same seed reproduces the trace, API tests pass, and figure/table captions name the metric's timing accurately. Existing full-run H1 remains reported as originally measured.

3. **Resolve the claims that need more than the current gate (targeted experiments, moderate effort).** Keep `balanced_gate_v1` as the primary gate. If the manuscript uses “intertemporal dilemma,” add short-horizon focal C/D returns at specified initial and depleted states and state the criterion in advance. If it uses “robust across policies,” test a small preregistered set of resource-contingent policies using the existing [`payoff.py`](../../cognitive_tools/payoff.py) machinery, with new seeds and simultaneous intervals. Neither test is needed merely to say the current **tested** game is a sequential commons dilemma. **Pass condition:** each extra label is backed by its own prespecified contrast; failing variants are disclosed as scope boundaries, not hidden by selecting a new policy pair after seeing results.

4. **Stress-test the visibility mechanism without changing H1/H2/H3 (moderate effort).** Use already recorded signed bias, majority mismatch, degree–action correlation, and network turnover to distinguish “degree inequality” from “a few high-degree agents with a particular action,” as suggested by [Lerman et al.](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0147617) and [Schrama et al.](https://www.sciencedirect.com/science/article/pii/S2589004225010922). Add a small seed-paired ablation or sensitivity grid for attention `k`, rewiring `mu`/threshold, and ecological coupling/recovery **only as a new robustness study**, not as post hoc replacement of the full campaign. **Pass condition:** the mechanism diagnostics and primary contrasts are reported side by side; robustness conclusions state which parameters and seed blocks were actually tested.

5. **Repair archival provenance before a strong reproducibility claim (moderate to high compute, low code labor).** The full campaign's input metadata contains two Git commits whose committed difference was presentation-only, but three source runs have `git_worktree_dirty=true` without a hash of the uncommitted contents; the payoff gate was also run in a dirty worktree ([full-run audit](../reviews/balanced-full-run-recovery-2026-10-01.md), [gate review](../reviews/balanced-capacity-payoff-gate-2026-10-01.md)). The clean recovered *analysis* does not reconstruct those input worktrees. Preserve original files and warnings. For publication-grade reconstruction, rerun the gate and, at minimum, the three affected full treatment runs from a clean pinned revision with a **new tag**, then recompute the combined estimates; a single-revision rerun of all 11 treatments is the strongest but costliest option. Archive immutable config/seed/manifest hashes and the retained data or a deposit identifier. **Pass condition:** every run used in the new primary analysis is traceable to a clean, pinned source tree and complete frozen configuration, with original and replication estimates compared transparently.

These are ordered by what each step resolves. The first two are documentation/software-verification work; step 3 is conditional on stronger *game classification* language; step 4 is a targeted mechanism study; step 5 addresses source reconstruction. A full port is **high implementation and scientific verification cost** because it replaces transition dynamics, action/observation semantics, and result schemas, then obliges a new gate and independent study. Reusing ODD/TRACE, official API tests, and the existing payoff/analysis code is much cheaper and preserves the question actually asked. This is an effort ranking inferred from the inspected mechanics, not a measured staff-hour estimate.
